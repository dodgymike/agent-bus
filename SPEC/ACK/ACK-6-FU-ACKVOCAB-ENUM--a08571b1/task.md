## Description

internal/signing/ackvocab_external_test.go pins the FROZEN five-token alphabet of the canonical ACK signing format against internal/ack's vocabulary. Its closure subtest is documented as tautological: `all` is a hardcoded 12-element literal because internal/ack keeps busClasses and recipientClasses unexported behind the BusEmitted()/RecipientEmitted() predicates and exports no enumerator, so no package outside it can walk the set. Consequence today: a THIRTEENTH recipient-emitted class added to the vocabulary would be accepted on the wire, would have no frozen spelling, would be refused by signing.CanonicalizeAck at signing time, and NOTHING would go red. Fix: export an enumeration from internal/ack (e.g. AllClasses() []Class) and iterate it in that test instead of the literal. This protects a PERMANENT wire format's alphabet, which is why it is worth doing rather than living with. Raised by the security gate as R1 (MEDIUM). Prospective files: internal/ack/state.go, internal/signing/ackvocab_external_test.go. Proof must be a MUTATION: add a fake 13th recipient class and show the test goes red.

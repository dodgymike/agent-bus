## Description

PROTOCOL.md section 8 carries a normative byte-layout table for the canonical MESSAGE signing format (format version 1). Two further canonical signed formats now exist with no equivalent section: internal/attest's bus attestation (AttestationFormatVersion=2, context agent-bus/bus-attest/2, shipped with this gap in RELAY-14) and internal/signing's recipient acknowledgement (AckFormatVersion=3, context agent-bus/recipient-ack/3). Both are PERMANENT signed wire formats whose only normative description lives in Go doc comments plus their testdata vector files. Add a PROTOCOL.md section for each, in the style of section 8.3, including the domain-separation disjointness argument (the three contexts differ in the length word itself: 0x13/0x16/0x19) and the standing requirement that any new artefact signed by an agent's messaging key preserves that disjointness. Note the ACK format's hard ceiling is 328 bytes. Raised by the reviewer as a non-blocking follow-up covering both formats, not just the new one. Prospective files: PROTOCOL.md.

## Description

cmd/agent-bus/ackback.go's TransitAck discards the relay.PeerAckResponse it gets from BackPropagator.Propagate, so federation.disposeUnrecordedAck returns AckSettlement{Duplicate:false} even when the ORIGIN answered duplicate:true. ACK-CONTRACT.md sec9.3's table says a 200 carries {accepted, duplicate} and the intermediate has the true answer in hand. hub.RecipientAckResult.Transit's doc argues the always-false case for the TERMINAL bus, which genuinely holds no table -- that argument does not cover an intermediate. Weigh forwarding it against the small amount it tells a downstream peer about the origin's state (a bound peer can only learn it by sending an ACK it is entitled to send, which itself sets the terminal). Found by the ACK-5 reviewer gate, 2026-08-21.

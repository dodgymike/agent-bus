## Description

store.RelayProvenanceByOriginMessageID (internal/store/provenance.go) is a projection over Store.ByOriginMessageID, which runs copyMessage and therefore deep-copies the whole message INCLUDING THE BODY, then throws it away. It sits on a path an authenticated agent drives once per POST /v1/ack for any well-formed-but-unrecorded key, and it takes the message store's EXCLUSIVE mutex and runs pruneLocked each time. Closing it needs a body-free resolver inside internal/store/store.go that shares byOrigin -> byIDLocked rather than duplicating the fallback reasoning. Declared honestly in provenance.go's own doc; raised by the ACK-5 security gate.

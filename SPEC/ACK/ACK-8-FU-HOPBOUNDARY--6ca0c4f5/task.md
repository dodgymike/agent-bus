## Description

ACK-8 was narrowed to the local-accept and settle boundaries in `internal/ack`. The HOP boundary is untested: a reviewer confirmed `internal/relay` contains NO test that imports `internal/ack` at all. Crash-inject the peer-hop ACK/NACK path and prove restart reconstructs the same state with no resurrection, no lost accepted ACK/NACK and no index reuse. Note the standing rule this must not violate: a hop ACK settles this bus's obligation TO THAT PEER and MUST NOT advance the sender-visible state in `ack.Store` (ACK-CONTRACT.md §8.2 note 3, §8.4) — there is deliberately no method on `ack.Store` a hop ACK could call, and the absence is the enforcement. Reuse the crash-child harness in `internal/ack/crash_ack8_test.go` (env-gated child + SIGKILL + a `DurableLog` wrapper that cuts at before-write / prepare / commit) rather than inventing a third one.

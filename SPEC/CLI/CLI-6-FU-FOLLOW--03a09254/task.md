## Description

Deferred out of CLI-6 (2026-08-14). CLI-6 description said `log` should support `--follow` to tail the audit log, but the data directory lock taken by `agent-bus log` is EXCLUSIVE and a running bus holds it -- the same constraint that forced CLI-11 description correction. This command can only run against a STOPPED bus, so there is nothing being appended for `--follow` to tail as currently scoped. Decide: either (a) add an ONLINE authenticated audit-read HTTP route the server exposes while running, which `agent-bus log --follow` (or a differently-scoped subcommand) polls/streams, or (b) drop `--follow` entirely and document why in CONTRACTS-CLI.md and AGENT_PROTOCOL.md. Do not attempt to tail bus.audit from an offline dirlock-holding reader -- by construction nobody is appending to it while the lock is held.

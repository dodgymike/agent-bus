## Epic description

Every mutating operation carries a client-supplied idempotency key and is safe to retry, per invariant 10 (CLAUDE.md, 2026-08-02): same key + same payload is a legitimate retry returning the original result; same key + different payload is a protocol violation that rejects, logs, and disconnects. The applied-key memory is durable and recovered on restart, never an in-memory-only cache.

## Description

AGENTS.md at repo root is NOT a symlink to CLAUDE.md -- it is a real, independently-tracked file that is a stale copy of it. As of 2026-08-21 the two files differ by roughly 107 diff lines (confirmed by running plain diff between them) and AGENTS.md was last written 2026-08-15. Any runtime that reads AGENTS.md as the project's standing instructions (the convention several agent runtimes follow, including Codex) is working from a six-day-old snapshot of the development protocol.

This was found the hard way. Commits 401f112 and 2828dcf corrected invariant 3's unauthenticated-route allow-list -- the code's unauthenticatedRoutes has six entries, the docs said five, and a test failure message said four. 2828dcf recast the passage as historical and claimed the counts had since been reconciled against the code. That claim was false when committed, because AGENTS.md still carried the original five-entry text at the corresponding line. b95d22d fixed that one paragraph and made the claim true. So the invariant-3 paragraph is now correct in AGENTS.md. The other roughly 100 lines of drift are untouched and unaudited -- nobody has diffed them to find what else is stale. That is this task.

Scope:

1. Diff AGENTS.md against CLAUDE.md and triage every difference. Classify each one: intentional-divergence (an AGENTS.md-specific preamble, if any), stale-copy (a CLAUDE.md correction that never propagated), or unique-to-AGENTS.md content that should be preserved rather than overwritten.

2. Decide and record the steady-state fix, because a hand re-sync only resets the clock until the next CLAUDE.md edit. Weigh the candidates rather than assuming one: make AGENTS.md a symlink to CLAUDE.md; generate AGENTS.md from CLAUDE.md via a small checked-in script; or add a doc-check guard (CI or a scripts/ script) that fails when the two diverge on shared sections. Whichever is chosen needs a DECISIONS.md entry -- this is a standing-contract surface, not a cosmetic one.

3. Second, smaller site to roll into this same task: README.md's line describing the healthz and info routes says both routes are unauthenticated by design. In context that line is scoped to the two curl examples immediately above it and is about response shape; two independent integrators judged it a weaker invitation to misread than the AGENTS.md paragraph was, so it is a wording clarification, not a correctness bug, and must not be inflated into one. It should simply stop implying that only two routes are anonymous. AGENT_PROTOCOL.md already enumerates all six unauthenticated routes correctly near its session-establishment section and needs NO change -- say so explicitly in the audit output so nobody edits a line that is already right.

DOC-TRUTH_DEEPDIVE.md rows 25 and 68 are what surfaced the multi-site nature of the original undercount (row 25: INVARIANTS.md / CLAUDE.md / AGENTS.md all said five instead of six; row 68: AGENT_PROTOCOL.md and README.md independently understated the same allow-list). They are a useful starting inventory for this audit, not a substitute for redoing it against the current tree.

Priority framing: P2. Nothing is currently wrong in main on the invariant-3 axis -- b95d22d closed that. The risk here is the unaudited remainder of the drift plus the absence of any mechanism preventing recurrence, which is why the steady-state fix matters more than a one-off re-sync of the remaining ~100 lines.

Definition of done: the two files (or the generated/symlinked replacement for AGENTS.md) no longer diverge on shared sections; the mechanism preventing re-divergence is in place and documented; the DECISIONS.md entry exists; the README wording is clarified without overclaiming a bug; and the proof_cmd below goes from FAIL to PASS.

## Description

DISCOVERED 2026-08-22 while filing the tiered-chain task set; not in the original decomposition. It is a hole, not a nice-to-have: without it the tiered chain is inoperable at commit time.

.claude/agents/integrator.md is the gate that actually enforces the chain -- integrator is the ONLY agent permitted to git commit, and its step 1 REFUSES a commit unless the report states reviewer AND security COMPLETED. A documentation agent has just rewritten that step (uncommitted, staged in the worktree at the time of filing) to encode the docs-and-tests-only carve-out from cancelled task 97a315af-70b3-4a64-8456-92335d8c9631: reviewer COMPLETED always; security COMPLETED unless the carve-out applies; and the integrator VERIFIES the carve-out mechanically from the diff (two greps over the exact pathspec -- paths that are neither .md nor _test.go, and filenames containing 'guard' -- judged by EMPTY OUTPUT, not exit status) rather than trusting the report's assertion.

Under the tiered chain that hand-rolled two-grep check becomes a SECOND, DIVERGING classifier sitting beside scripts/change-tier.sh. Two classifiers that can disagree is exactly the drift this scheme exists to remove, and the integrator's copy is the one with commit authority.

Scope: replace the integrator's inline greps with a call to scripts/change-tier.sh, so the gate it enforces is the tier the classifier measured. Keep the properties the documentation agent's version established, all of which must survive: default-deny on an unclassifiable path; judged by EMPTY OUTPUT not exit status (grep exits 1 on no match); the checks stated as a FLOOR, not the whole rule; and the integrator verifying MECHANICALLY from the diff rather than accepting the reporting agent's assertion of its own tier -- that last property is the whole point of the gate and must not be weakened into "trust the kind=tier note".

Also carry the measurement the documentation agent recorded there, which the classifier itself must honour (it is the same defect as T-03's diff-basis contract): `git diff HEAD --name-only` OMITS a NEW UNTRACKED .go file entirely -- empty output, exit 0 -- while `git status --porcelain` shows it as `??`. A diff-based classifier that does not add untracked files under the pathspec measures a change that is missing its newest file.

Do not claim until the documentation agent's edit is committed, or this task will be written against a version of integrator.md that no longer exists.

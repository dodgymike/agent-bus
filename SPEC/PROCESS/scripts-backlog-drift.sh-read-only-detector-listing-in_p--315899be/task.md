## Description

See DONE-NOT-FLIPPED_DEEPDIVE.md. The done-not-flipped drift is invisible: nothing surfaces the in_progress tasks that are actually shipped. This is the CHEAP, read-only complement to the manual reconcile HANDOVER-BACKLOG-RECONCILE (43d14776) -- it MUTATES NOTHING, so it does not compete for spec-keeper and is safe to run any time.

A new scripts/backlog-drift.sh: pull GET tasks?limit=1000, for each in_progress (and optionally todo) task with a stored proof_cmd, do the CHEAP checks first -- does the named test symbol exist at HEAD (git grep func Test<name> HEAD), are the commit shas in the journal in HEAD ancestry (git merge-base --is-ancestor) -- and only optionally run the proof through scripts/proof-check.sh in an overlay of HEAD. Print a table: task | priority | proof-status (SYMBOL-PRESENT / PROOF-PASS / PROOF-RED / VACUOUS / UNVERIFIABLE). It gives spec-keeper a worklist of flip candidates and gives triage a way to avoid dispatching a feature-runner onto already-done work.

HONOUR: proof-check.sh script-directory / overlay defects (existing tasks 521d68b5, 71cdaef8) mean a naive run gives confidently-wrong results -- the detector must default to the cheap symbol/ancestry checks and mark proof-execution as opt-in. Do NOT auto-complete anything; output only.

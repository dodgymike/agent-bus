## Description

Proposed signal 5 -- "new/changed exported identifier in client/" -- is not computable by a shell script from a diff, and shipping a grep that pretends otherwise is worse than not having it. A grep for `^+func [A-Z]` misses: a changed SIGNATURE on an existing exported func (a -/+ pair), a new field on an exported struct, a changed exported const value, a widened interface, and a method added to an exported type in another file. It false-positives on doc comments and moved code.

client/ is outside internal/ by invariant 7, so its surface is genuinely public and genuinely T4 material. Decide between:

1. A real API-surface diff -- a committed baseline snapshot (go doc-style or apidiff) compared on each run. Accurate, but adds a toolchain dependency and a baseline file that must be maintained; needs a DECISIONS.md entry.
2. Path floor: any non-test change under client/ floors T3, and T4 promotion for a public-surface change is an explicit reviewer judgment recorded in the kind=tier note.

Recommendation is (2) unless (1) is cheap: this repo has no CI to keep a baseline honest, and a stale baseline is a signal that silently stops firing. Whichever is chosen, record it in DECISIONS.md -- this is a decision, not an implementation detail.

Proof note: the stored proof_cmd assumes a signal ships. If the path-floor option is taken, the plane-map fixture from T-04 covers it and the proof must be changed to the DECISIONS.md doc-check.sh section assertion instead.

## INHERITS F1 AND F2 FROM T-03 (2026-08-22, security gate)

**This signal classifies by PATH, and therefore inherits findings F1 and F2 recorded on T-03
(b2567ffd-190d-4aff-8cc2-f6a2eb2d613e).** Both are measured, not theorised:

- **F1 (renames):** `git status --porcelain` prints a rename as ONE line, `R  old -> new`, so a
  check anchored at `^` never sees the target and a check testing the line end never sees the
  source. **This signal must consume the `git status --porcelain --no-renames` file set**, in which
  the rename is split into `D old` + `A new` and both halves are classified.
- **F2 (fails open):** `git status --porcelain -- <pathspec matching nothing>` prints nothing and
  exits **0**. **This signal must NOT treat an EMPTY file set as low-risk** -- "measured T0" and
  "could not measure" are different outcomes, and the second is an error exit, not a result.

**This signal needs a RENAME FIXTURE in its own right** -- not merely coverage in T-03's tests --
shown RED before the signal is implemented, with the RED output quoted in the task's `kind=report`.

## Description

Reviewer finding on AUTH-10, raised as NON-BLOCKING at the final gate (which returned PASS).

AUTH-10 corrected an overclaim: an agreeing re-revocation was described in two places as
"BYTE-IDENTICAL" when the actual predicate, `operatorRecordsAgree` (internal/auth/operator.go),
compares only the fields that BIND the identity or the revocation — AuthPublicKey, CertFingerprint,
CreatedAt, RevokedAt, RevokedReason — and deliberately IGNORES `Label` (it authorises nothing) and
`Name` (it is re-derived from `operator_id` and re-checked by `validateOperator` in BOTH
`EncodeOperator` and `DecodeOperator`, so it cannot differ).

That correction now appears in THREE operator-facing places:
  - internal/auth/operator.go, the `case operatorRecordsAgree(prev, o):` comment
  - internal/auth/operator.go, the disagreeing-revocation ERROR log string
  - CONTRACTS-ONDISK.md, the `Apply` fold table and the paragraph beneath it

NO TEST ASSERTS IT. Specifically, nothing exercises: a second revocation record for the same
operator, identical in every bound field but carrying a DIFFERENT `label`, replayed through
`OperatorRegistry.Apply`, is folded in SILENTLY (no ERROR line) and does not alter stored state.

WHY THIS MATTERS MORE THAN A NORMAL COVERAGE GAP: this repo rates a load-bearing comment that is
false as a defect in its own right, and AUTH-10 was gated twice over exactly that species (the
"suffix is never all digits" claim and the "NOT AN ENUMERATION ORACLE" claim, both false when
written). The fix replaced one unverified claim with a more precise unverified claim. A test is what
turns it into a checked one — and it is the test that goes red if anyone later "tidies"
`operatorRecordsAgree` into a whole-record comparison, which would start reporting a benign
label edit as corruption or tampering in an ERROR line.

Add the test to internal/auth/operatorprincipal_test.go beside the existing
`TestOperatorPrincipal...Apply...` cases, keeping the `TestOperatorPrincipal` prefix so the existing
proof_cmd regex covers it. Assert BOTH directions: label-differs is silent, and a bound-field
difference still logs loudly.

proof_cmd suggestion: go test -race -count=1 -run 'TestOperatorPrincipal' ./internal/auth

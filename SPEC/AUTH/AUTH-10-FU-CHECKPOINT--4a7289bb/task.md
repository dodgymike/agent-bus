## Description

Reviewer finding on AUTH-10.

`auth.OperatorRegistry` implements `wal.Applier` but NOT `wal.CheckpointParticipant`: it has no
Kinds()/Snapshot()/Restore(). Harmless today because `cmd/agent-bus/main.go` does not set
`Checkpoints:` on the operator kind — but the moment WAL checkpointing covers this log, operator
records are dropped at checkpoint and every operator silently disappears at the next start.

This is a LATENT durability defect, not a live one. It should be closed before, or in the same
change as, any work that enables checkpointing over the operator record kind. See
CONTRACTS-ONDISK.md "WAL checkpoint generations (format version 7)" for the participant contract.

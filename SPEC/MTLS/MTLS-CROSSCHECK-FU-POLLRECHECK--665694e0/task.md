## Description

MTLS-CROSSCHECK adds a SECOND property that a parked long poll can outlive. The cross-check runs at request ADMISSION only, exactly as the session check does, so a poll admitted the instant before an operator retires a binding runs to the end of its poll timeout -- bounded by hub.MaxPollTimeout (5 minutes), up to hub.MaxWaitersPerAgent (32) parked polls. AUTH-2-FU-POLLEXPIRY (03d7ca66-110e-4560-803e-1a7825d1accc) already owns capping the wait at min(pollTimeout, time.Until(principal.ExpiresAt)) and re-authenticating before delivering; it must now ALSO re-run the certificate cross-check before delivering, not the session alone. Cross-reference recorded on that task's description already; this task exists so the requirement is not lost if that one is re-scoped.

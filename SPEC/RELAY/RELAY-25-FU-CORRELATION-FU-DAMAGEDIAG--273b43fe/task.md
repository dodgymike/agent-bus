## Description

Raised by the security gate. `classify_zero_delivery` in scripts/fed-smoke.sh returns 2 ("audit output is malformed") only for INVALID JSON. A well-formed `{"damaged":true,...}` line -- which `agent-bus log --json` emits for a record that would not decode -- parses fine, matches no digest, and is therefore attributed as return 1, "relay not established".

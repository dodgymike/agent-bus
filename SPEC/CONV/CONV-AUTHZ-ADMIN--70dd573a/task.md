## Description

**FILED BLOCKED ON PURPOSE. Do not start this by inventing an admin identity.**

The operator asked for "only the channel creator may change the receipient list, **or an admin**".

**THERE IS NO ADMIN PRINCIPAL IN THIS SYSTEM TODAY.** All authentication here is AGENT
authentication: every route authenticates except enrolment, session begin/complete, `/healthz` and
`/v1/info`, and all of it resolves to an agent. There is no non-agent identity to check against.

This is the **SECOND** request to depend on that gap. `INVMINT-2`
(`ef18b37a-72b5-4b00-865f-edac288a0659`, "introduce an OPERATOR PRINCIPAL -- a bus-scoped, non-agent
identity") was filed for exactly it, most naturally an operator client certificate under invariant
11's mTLS. A HARD `blocks` edge is wired from INVMINT-2 to this task.

**SCHEDULING REALITY, stated so nobody is surprised:** INVMINT-2 is P3 and is itself `blocked by`
INVMINT-1 (the invite-minting AUTHORITY MODEL decision). So this arm sits behind a blocked P3. If
CONV-SUCCESSION rules `ADMIN_ESCAPE_HATCH`, that chain becomes CONV's critical path and the operator
must be told.

**AMBIGUITY -- FLAG IT, DO NOT RESOLVE IT SILENTLY.** "Admin" may mean:
  (a) INVMINT-2's bus-scoped operator principal (an mTLS client certificate); or
  (b) the ADMIN epic's `agent-busadm` console -- which is UNBUILT, and whose D1 ruling is a browser
      console on LOOPBACK.
These are DIFFERENT principals with different trust properties. Loopback-console authority and a
certificate-bearing operator identity are not interchangeable, and picking one silently decides a
security boundary the operator has not been asked about.

Definition of done (once unblocked):
  1. Confirm which principal INVMINT-2 landed, and confirm with the OPERATOR that it is the "admin"
     they meant.
  2. Admin membership-change authorization, refusing everything that is neither creator nor that
     principal.
  3. Tests including a negative: an ordinary agent, however privileged-looking, is refused.
  4. CONTRACTS-HTTP.md + AGENT_PROTOCOL.md + CLI surface per invariant 7.

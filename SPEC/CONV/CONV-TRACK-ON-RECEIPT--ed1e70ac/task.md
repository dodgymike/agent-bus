## Description

The operator's request, verbatim: "When a server first receives a conversation message it should
start tracking it so its clients can be aware and send using the uuid to send messages rather than
track the other participants in the conversation."

**MUST NOT LAND BEFORE OR WITHOUT CONV-PEERQUOTA. A hard `blocks` edge is wired.** Implicit,
peer-triggered state creation with no bound on DISTINCT KEYS is the attack this repo forged
end-to-end on 2026-08-15 (RELAY-FU-IDEM-METER-BY-PEER, `8774f265`): 32,766 messages from ONE
authenticated peer, each asserting a DISTINCT label, all HTTP 200, zero refused. Shipping this task
un-gated recreates that hole with conversation ids as the currency.

Everything a peer asserts is INPUT TO VALIDATE, NEVER AN ASSIGNMENT TO TRUST (invariant 1). A peer
asserting a conversation id does not thereby create a conversation on our terms: the local record is
OURS, minted/derived under our rules, and the peer's assertion is evidence, not authority. In
particular a peer must not be able to assert a conversation id that COLLIDES with or IMPERSONATES a
locally-minted one -- which is exactly why CONV-ID-SHAPE's attribution question must rule first.

Loop prevention rides the existing traversed-bus path (invariant 10: loop prevention is a
COMPLEMENT to idempotency, never a substitute). Do not invent a second loop-prevention mechanism for
conversations.

Definition of done:
  1. On first receipt of a message bearing an unknown conversation id, the bus creates a local
     tracking record -- ONLY within the CONV-PEERQUOTA bound, and refusing loudly past it.
  2. Local clients can discover and address the conversation by id thereafter.
  3. A test that a peer-asserted id cannot collide with or impersonate a locally-minted one.
  4. A test that tracking is bounded per authenticated peer (the CONV-PEERQUOTA property, asserted
     from this side too).
  5. CONTRACTS-HTTP.md / CONTRACTS-ONDISK.md updated.

Blocked by CONV-PEERQUOTA and CONV-ID-SHAPE.

Parallel-safety: internal/relay + internal/hub, heavily contended by RELAY. Coordinate.

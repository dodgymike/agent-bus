## Description

**OPERATOR CONSTRAINT, verbatim (2026-08-15): "only the channel creator may change the receipient
list, or an admin, and no backfill". This task is the CREATOR arm. The ADMIN arm is
CONV-AUTHZ-ADMIN and CANNOT ship yet -- see below.**

The creator is recorded DURABLY in the conversation record. Unlike the user-supplied NAME (see
CONV-NAME-INV6), the creator is a fully-qualified agent id -- routing/identity metadata -- so it
sits comfortably inside invariant 6. Do not lump the two together.

The creator is taken from the AUTHENTICATED PRINCIPAL in the request context at create time, never
from a body field (invariant 1). Membership-change authorization compares the authenticated
principal against the durably-recorded creator, FULLY QUALIFIED (invariant 2) -- a bare or
unqualified name must be REFUSED, and `<bus>.planner-3` is NOT `<bus>.planner-4`.

**FAIL CLOSED, AND SAY SO.** Until CONV-AUTHZ-ADMIN lands, a non-creator membership change is
REFUSED. That refusal must be a documented, specific error that names the admin arm as the missing
capability -- **"or an admin" MUST NOT become a silent TODO that ships as creator-only and quietly
diverges from what the operator asked for.** The CLI help and AGENT_PROTOCOL.md must state that the
admin path is not yet available, not omit it.

Definition of done:
  1. The creator field, durable, from the request context.
  2. Membership-change authorization enforcing creator-only, with fully-qualified comparison.
  3. A test that a NON-creator participant is refused, and a test that a re-enrolled agent with an
     ADVANCED SUFFIX is refused (it is a different principal -- see CONV-SUCCESSION).
  4. A refusal error that explicitly names the not-yet-available admin path.
  5. Docs state the current limitation plainly.

INVARIANT 7 (same task, non-negotiable): ship the `cmd/agent-busctl` subcommand AND the
AGENT_PROTOCOL.md entry IN THIS TASK -- a capability without its CLI surface is the missing half of
the task, not a follow-up. `--json` everywhere, stable documented exit codes, no interactive prompt.
`scripts/bus-*.sh` wrappers are RETIRED; adding one is FORBIDDEN (only bus-serve.sh survives). The
client package cannot live under `internal/`. Verify by running the COMPILED CLI against a running
server -- never hand-written curl.

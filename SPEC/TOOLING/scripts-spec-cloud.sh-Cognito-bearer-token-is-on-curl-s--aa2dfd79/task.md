## Description

SECURITY. Filed 2026-08-14 per coordinator, do NOT implement yet.

scripts/spec-cloud.sh's _call() (around line 93) does:
  curl -sS -w $'\n%{http_code}' -H "Authorization: Bearer $tok" "${passthru[@]}" "$HOST$path"
The bearer token is interpolated directly into a curl argv argument. Process command lines are world-readable via /proc/*/cmdline (and via `ps`) for the lifetime of the call, so any local process (any user on a shared box, or any process on this one) can read the live Cognito credential. Same defect class as the SPEC_CLOUD_PASSWORD leak already fixed in this script -- this is the same mistake recurring on the token instead of the password.

PRE-EXISTING, NOT caused by the CONTEXT-SPEC-TREE work -- but that work AMPLIFIES the exposure window and should be recorded as a distinct fact, not conflated with the defect's age: a mirror regeneration used to make roughly 2 API calls (list + export), so the token sat on argv only momentarily, call after call. CONTEXT-SPEC-TREE's real-relations-by-default fetch makes ~520 additional requests (one per task -- there is no bulk relations endpoint), so the token now sits on argv continuously for roughly the ~50-70s a full regeneration takes. The defect is old; the exposure is newly amplified, by roughly 2 calls -> ~520 calls per regen.

PRIORITY: P1, not P0. It leaks a live credential to any local process; the operator being sole user of this machine is why it isn't P0, but sole-operator does not make a world-readable credential fine -- it only lowers blast radius, it does not remove the defect.

FIX SHAPE (standard, do not implement here -- filing only): stop putting the Authorization header on curl's argv. Use curl's `--config -` (or `-K -`) or `-H @-` equivalent to pass the header via stdin instead, so it never appears in argv/`/proc/*/cmdline`/`ps`/shell history. Whatever the exact curl invocation shape, the token must not be a literal argv token at any point in the process's lifetime. Apply the same fix discipline used for the SPEC_CLOUD_PASSWORD leak this script already had fixed.

Do NOT implement yet -- coordinator instruction. This is a filing-only task; a security review of the exact fix shape should happen before/alongside implementation given the credential-handling stakes.

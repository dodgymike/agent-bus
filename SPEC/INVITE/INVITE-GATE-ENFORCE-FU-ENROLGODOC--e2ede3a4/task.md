== WHY THIS ONE MATTERS MORE THAN A NORMAL STALE COMMENT ==

Invariant 7: the client package **cannot live under `internal/`** precisely so agents can EMBED it. This is therefore not an internal note -- it is API documentation on an exported field, and it appears in `go doc` output and in every IDE hover for `Invite`. It tells an embedder that passing `nil` is fine and that the bus accepts un-invited enrolment. An embedder who believes it ships a client that cannot enrol at all: the bus now answers 403.

Note the comment's LAST sentence is still correct and should survive -- the bus refuses, not the client. That distinction is deliberate and load-bearing; keep it.

== SCOPE ==

Comment-only change to `client/enrol.go`. Do not change behaviour -- `Invite` stays a pointer and `nil` stays legal at the type level.

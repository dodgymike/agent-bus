## Description

Invariant 7 gap found while writing the INVITE-GATE-ENFORCE docs: enrolment.invite_required is the field an agent must read to know whether it needs an invite before enrolling, but there is NO agent-busctl subcommand that fetches the discovery document. agent-busctl currently has agents/broadcast/client-cert/enrol/logout/pin/send/use/watch/whoami only -- an agent cannot check the buses enrolment posture (invite_required, and whatever else the discovery document carries) through the compiled client at all, which is a gap against invariant 7 (the compiled Go CLI is THE client; nobody hand-writes HTTP). Add a discover (or similar) subcommand that fetches and prints the discovery document, --json included, following the same conventions (stable exit codes, no interactive prompt) as every other subcommand.

Proof: agent-busctl discover --json against a running throwaway bus prints a JSON object containing an invite_required (or equivalent enrolment) field, exercised through the compiled binary end to end, never curl.

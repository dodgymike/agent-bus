## Description

internal/auth/inviteenrol.go:285-289 silently ignores any kind with no registered applier -- correct for store.RecordKind and hub.SeqFloorRecordKind, which the hub applies in its own replay pass. But the dispatch table is now a map literal in cmd/agent-bus/main.go, and dropping or typoing invite.RecordKind there would silently discard every standalone invite MINT and REVOKE at replay, with NO log line at all. Direction is fail-closed (invites become unknown, hence unredeemable), but invariant 6 requires every discard to be logged loudly and specifically. NewMultiplexApplier validates empty maps, empty kinds, nil appliers and the forbidden composite kind, but not that the kinds handed to it are the ones this build actually writes. Raised by the security gate 2026-08-14.
